# D&D Hub v0.4.0

## GM Mode

`v0.4.0` adds the first local GM interface on top of the existing campaign system. No server, account, Internet connection, or real-time synchronization is introduced in this release; those remain part of v0.5.

### Added

- GM Dashboard for the selected campaign.
- Campaign overview with player, character, linked-character and session counts.
- Player/character overview with HP, AC and initiative visible from the GM interface.
- Read-only character sheet viewer for the GM, including core stats, attributes, inventory, spells, abilities, bio and notes.
- Campaign management shortcut from the GM Dashboard.
- Local Session Tools.
- Active session with title and persistent GM notes.
- Session start/end timestamps and session history.
- Only one active session is allowed per campaign.
- Session data is included in full backup/restore.
- Database migration from schema v6 to v7.

### Scope boundary

The following remain outside `v0.4.0`: local GM server, player connections, WebSocket synchronization, reconnect/state recovery, conflict resolution and Battle Mode.
