# D&D Hub v0.4.1

Патч поверх `v0.4.0`.

## Изменения

- Добавлено изображение в раздел **Био** персонажа.
- Изображение выбирается через системный файловый диалог, сохраняется локально в SQLite и входит в экспорт/backup персонажа.
- Добавлена возможность заменить или удалить изображение.
- GM-просмотр био теперь показывает сохранённое изображение.
- Текст и иконки на основных оранжевых `FilledButton` теперь отображаются белым цветом вместо стандартного фиолетового `onPrimary`.
- Версия базы данных повышена до `v8`; для существующих баз добавляется `bio_image` с пустым значением.
- Добавлен тест сохранения и чтения изображения био.

## Ограничение

Размер выбранного изображения ограничен 8 МБ, чтобы не раздувать локальную базу без контроля.
