# D&D Hub v0.3.1

## Android & import/restore fixes

`v0.3.1` is a maintenance release for `v0.3.0`. No new product scope is introduced.

### Fixed

- Existing Android databases are now repaired safely when older builds stamped a schema version without creating all v0.3 tables/columns.
- Backup/restore on Android no longer fails because of missing character columns such as `portrait_path` or `ability_generation_method`.
- Campaign navigation is available in release builds on narrow Android screens.
- Character `.dndhub` export/import now preserves XP history.
- Imported XP transactions are recreated for the new character ID, so references remain valid and source transaction IDs are not reused.
- XP history import accepts both current SQLite-style field names and camelCase portable keys.

### Verification

- Windows debug build: verified manually.
- Android debug APK: built and installed successfully.
- Android existing-database migration: verified manually.
- Android backup/restore after migration: verified manually.
- Campaign navigation in release layout: verified manually.

### Upgrade notes

Existing local databases do not need to be deleted. The v0.3.1 database layer performs additive schema repair during database open.

The existing `v0.3.0` release remains available for historical reproducibility. `v0.3.1` should be used for current Android and import/restore workflows.
