# D&D Hub v1.0.2 — Battle Notes & Character Setup Improvements

This update improves the Battle Mode workflow and character creation.

### Added
- Added private battle notes for the GM and each player. Notes are autosaved locally and remain separate between the GM and players.
- Added a character level selector from level 1 to level 20 in the character configurator.
- Automatically sets XP to the selected level's minimum threshold when a new character is created or its level is changed.
- Preserves the existing XP of an edited character when its level is left unchanged.

### Improved
- Battle action drafts now survive closing the action composer. Attack and damage formulas, roll results, target selection, and other entered fields are restored when the same action is opened again after checking its details.
- Battle action draft data is cleared after submitting the action from the composer.
