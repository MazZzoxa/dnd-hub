# D&D Hub v1.0.3 — Mobile Game Discovery & Proficiency Progression

This update improves the mobile LAN connection flow and keeps character proficiency bonuses aligned with D&D 5e level progression.

### Improved
- Redesigned nearby-game cards for narrow phone screens. Campaign name, GM, player count, LAN address and the Connect button now use a readable vertical layout instead of competing for a single row.
- The desktop layout remains compact and horizontal when enough width is available.
- The character configurator now displays proficiency bonus as a level-derived, read-only value. Changing the selected level updates the displayed bonus immediately.

### Fixed
- Proficiency bonus now follows D&D 5e level brackets automatically: levels 1–4 `+2`, 5–8 `+3`, 9–12 `+4`, 13–16 `+5`, and 17–20 `+6`.
- Proficiency bonus is recalculated when XP changes through normal character updates, direct XP awards, and Session Workspace XP rewards.
- Added unit coverage for all proficiency bonus brackets and boundary levels.
