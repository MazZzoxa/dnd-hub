# D&D Hub v0.6.1 — Battle Workspace

This release extends the v0.6 Battle Mode MVP into a synchronized combat workspace for GM and Players.

## Included

- GM-controlled Battle Turns with sequential history
- Initiative display as reference information, without automatic turn tracking
- Battle Character View with `Overview` and `Actions`
- Reuse of existing `AttackModel`, `SpellModel`, `AbilityModel` and `ItemModel`
- User-defined action formulas and integrated dice rolls
- `Self`, `Ally` and text-only `External` targets
- Player `Action Request` flow
- GM `Approve`, `Modify` and `Reject`
- Original submitted Action Request values preserved in metadata after GM modification
- Character State updates for approved Self/Ally effects
- Structured append-only Combat Journal
- Last 100 journal entries included in reconnect snapshots
- SQLite persistence and LAN synchronization for Battle workspace entities

## Intentionally not implemented

This release does not introduce an Enemy/NPC model or automatic combat rules. It does not automatically resolve hit/miss, damage rules, resistances, vulnerabilities, critical hits, conditions, initiative order, rounds, movement or resource consumption.

The Battle Mode remains a tool for managing combat state, actions, synchronization and history while the GM remains responsible for rules and game consequences.
