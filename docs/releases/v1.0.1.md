# D&D Hub v1.0.1 — Post-release Fixes

Maintenance release addressing issues discovered while using D&D Hub v1.0.0. This update focuses on character stat entry, Battle Action dice handling, clearer history and LAN session capacity.

### Changed

- Added `−` / `+` controls for all six ability scores in the Character Configurator. The D&D ability modifier is displayed and updates automatically as the score changes.
- A successful attack or effect roll can only be made once per field during a Battle Action. The rolled formula is locked after the result is produced to prevent rerolling by changing the expression.
- Battle Action review cards and Session History retain and display individual die values, formulas and roll totals for attack, damage and healing rolls.
- Session History now displays the GM-provided reason when an action is rejected.
- Removed the LAN server's player connection cap. Game discovery now reports the session as unlimited instead of displaying a fixed player maximum.

### Verification

- Server regression suite: `30 passed`.
- Python server syntax compilation passed.
- Flutter/Dart SDK is not installed in the build environment, so `flutter analyze` and platform builds could not be run here. Client changes were reviewed statically but still need a local Flutter build/test before publishing.
